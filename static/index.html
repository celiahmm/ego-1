EGO-1

Un petit robot chargé de sauver la planète. Vous, vous vivez votre vie. On verra bien. Passez le test sur votre téléphone, puis décidez ensemble de ses 12 jours : la majorité l'emporte.

Je joue

Scannez le QR code affiché à l'écran ou entrez le code de la partie. Pas de compte, pas d'infos personnelles.

J'anime

Créez une partie et projetez l'écran dans la salle. Aucun compte nécessaire, et plusieurs parties peuvent tourner en même temps.
